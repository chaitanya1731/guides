# Engineering Guides

In-depth technical learning notes and reference guides for cloud-native and platform-engineering projects I work with. Each guide is a self-contained deep-dive: architecture, components, APIs, design patterns, and the surrounding ecosystem — written to be read top-to-bottom or used as a lookup reference.

Each guide is written in Markdown (with Mermaid diagrams) and also published as a browsable, printable web page.

## How this repo is organised

`main` holds **only the sources** — the Markdown guides and the build script. The
printable HTML is generated by CI and published to the **`gh-pages`** branch, which
GitHub Pages serves. No HTML is committed to `main`.

```
guides/                          (main branch — source only)
├── build.sh                     # generates the printable HTML from the Markdown
├── .github/workflows/pages.yml  # rebuilds + publishes to gh-pages on every push
├── README.md
└── <project>/
    └── README.md                # the guide (source of truth; renders on GitHub)
```

## Publishing

Publishing is automatic: **every push to `main`** triggers the workflow, which runs
`build.sh` and pushes the freshly rendered pages to the `gh-pages` branch. The live
site updates a minute or so later. There is nothing to run by hand.

To add a guide, create `<project>/README.md`, commit, and push — a card for it appears
on the landing page automatically.

## Building locally (optional)

The Markdown is the source of truth; you only need this to preview locally:

```bash
./build.sh                     # build every guide + the landing page
./build.sh models-as-a-service # build one guide
```

The generated `index.html` files are self-contained (Mermaid + Markdown via CDN) and
include print styles — open one in a browser and use **Print → Save as PDF** for an
offline copy. These files are git-ignored on `main`.

## Reading offline

- Browse any `README.md` directly on GitHub — Mermaid diagrams render inline.
- Or run `./build.sh` locally and open a project's `index.html`, then print to PDF.
